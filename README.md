# Dino Runner

Dino Runner is an endless runner game where you control a dinosaur and avoid obstacles.

<img width="1153" height="648" alt="image" src="https://github.com/user-attachments/assets/7c6403ac-f3a3-40b4-8e82-c19f2654423b" />

## 🎮 How to Play

## Controls
- Spacebar → Jump
- Down Arrow → Duck

## Gameplay
- The dinosaur runs automatically.
- Your goal is to avoid obstacles like rocks or enemies.
- Jump at the right time to survive.
- The game gets faster over time, making it more challenging.
- Objective
- Stay alive as long as possible.
- Try to beat your high score.

## ▶️ How to Run the Game
- Download the game from the Releases section.
- Extract the ZIP file.
- Run the game:
 Windows: open the .exe file

## 💡 Tips
- Time your jumps carefully.
- Don’t spam jump — be precise.
- Focus as the speed increases.

## Feature
- Infinite Scrolling: The Camera and Dino constantly move forward, and the ground automatically loops back in front of them so the level never ends.
- Three Ground Obstacles: The game randomly spawns Boxes, Ridges, and Stones on the ground.
- Animated Flying Obstacles: The game spawns animated Birds that flap their wings and fly at two distinct heights (low and high).
- Dynamic Difficulty: As the score increases, the game gets harder by spawning up to 3 ground obstacles tightly clustered together.
